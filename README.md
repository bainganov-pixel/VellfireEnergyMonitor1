# Vellfire Energy Monitor — Teyes CC3L / UIS7862 / Android 10

Стартовый исходный проект для горизонтального экрана Android 10.

Важно: это исходный проект, не готовый APK. В версии 0.1 есть макет интерфейса, Bluetooth SPP для сопряжённого ELM327, инициализация адаптера и тестовый запрос оборотов 010C. Демо-кнопка показывает примерные состояния, не реальные энергопотоки. Toyota Hybrid PID и данные батареи ещё не реализованы.

Сборка: Android Studio, JDK 17, Android SDK. После Gradle Sync выберите Build > Build APK(s). Debug APK обычно находится в app/build/outputs/apk/debug/app-debug.apk.
